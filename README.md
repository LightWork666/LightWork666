### Projects

**[impact-engine](https://www.npmjs.com/package/impact-engine)**
CLI tool that maps dependency failure surfaces before they break your build. Extracts full dependency graphs with provenance tracking, computes blast radius for any removal or version change, surfaces structural hotspots via collapse sensitivity analysis, and runs a dependency doctor that catches version drift, duplicates, peer mismatches, and lockfile inconsistencies — all emitting a unified JSON schema for machine consumption.

**[Sieve](https://github.com/LightWork666/Sieve)**
Language-agnostic LLM token optimization middleware. Rust core exposed via PyO3 (Python) and reimplemented in pure Go. Strips conversational filler in-flight before it hits your LLM API — less tokens, faster TTFT, lower cost.

**[Compression Playground](https://github.com/LightWork666/Compression)**
Browser-native image compression analyzer. Compare JPEG, PNG, WebP, AVIF side-by-side with PSNR/SSIM metrics. All processing runs in-browser via WebAssembly — nothing leaves your machine.
